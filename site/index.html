Brain Signals Lab

Does the model work for someone it has never seen?

Erfan's choice
Participant-held-out cross-validation on public PhysioNet motor imagery — five folds, 50 people, CSP + LDA.
Baseline / failure mode
Most-frequent-class label at 50.4%; random trial splits would inflate scores when the same person appears in train and test.
Result
Mean accuracy 61.8%; participant median 57.8%. Saved reports in the static viewer — no retraining in the browser.
Limits
One public dataset; engineering comparison only, not clinical or neuroscience evidence.

OpsDesk

When should a support assistant stop and ask?

Erfan's choice
Expire approval when a ticket draft changes; require explicit re-approval before simulated execution.
Baseline / failure mode
Rules-only proposals vs a local model on 60 held-out fictional tickets — neither is production support software.
Result
Rules: 37/60 fully correct proposals; local model: 25/60. Duplicate execution requests return the first receipt.
Limits
Browser fixture simulates the workflow; the Python service runs locally. No real tickets or customer systems.

Reachboard

What happens when someone submits a campaign twice?

Erfan's choice
Fix quotes at submission, scope drafts per advertiser, and keep audit history unchanged on retries.
Baseline / failure mode
A repeat submission could change a quote or create a second audit entry; a draft must belong to the advertiser who opened it.
Result
Django backend enforces ownership and locked totals; public static fixture shows fictional placements at draft (75 RB credits).
Limits
The GitHub Pages demo is a browser simulation. The Django app is separate and local; the fixture does not run that backend.
