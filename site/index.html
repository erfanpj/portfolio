Brain Signals Lab

Motor-imagery EEG on public PhysioNet data, scored on participants the model never trained on.

I kept each participant's recordings in a single fold. Across 50 people and five folds, CSP + LDA averaged 61.8% accuracy. A most-frequent-class baseline reached 50.4%. The viewer loads saved reports only—nothing retrains when you open a page.

Try it: open Participants and filter below chance to see spread across people.

Engineering results on one dataset—not a clinical or neuroscience claim.

OpsDesk AI

A fictional support desk where proposals cite the handbook and a person approves before anything runs.

Changing an approved ticket proposal invalidates its approval. A second execution request returns the first receipt. I compared a rules baseline with a local language model on 60 fictional tickets: the rules produced 37 fully correct proposals and the model produced 25.

Try it: approve a plan change on the fixture, then repeat the run and watch duplicate handling.

The browser simulates the workflow; the Python service runs locally. All customer data is synthetic.

Reachboard showcase

I built a fictional media-buying catalogue where the server owns cart totals and campaigns move draft → awaiting payment.

I seeded six packages with channel, placement, and RB credits prices. In the sample journey, add Echo Weekly (35) and Northline Sound (40), review cart → draft, and the locked campaign total is 75 credits. When I run Django locally, checkout is POST-only with CSRF and per-user reset—that backend is separate from the public browser simulation linked below.
