Selected projects

Brain Signals Lab — EEG motor imagery · *Completed evaluation · public data* | github.com/erfanpj/brain-signals-lab
• Tested whether imagined left- vs right-fist movement can be decoded from the EEG of people the model has never seen: public PhysioNet data, 50 participants, 2,245 trials, five participant-held-out folds; band and settings chosen on training participants only.
• CSP + LDA reached 61.8% mean accuracy vs a 50.4% majority-class baseline (participant median 57.8%); a reduced EEGNet reached 53.9%. A static viewer shows every participant’s result. Engineering result on one public dataset, not a clinical or neuroscience claim.
OpsDesk AI — human-approved support automation · *Local prototype · browser demo is a simulation* | github.com/erfanpj/opsdesk-ai
• Built a local support desk: retrieval over a handbook (keyword, BM25, dense, hybrid), structured proposals from a small local LLM, explicit human approval and mock execution.
• Approval is invalidated when a proposal changes; execution is idempotent per approval id; every step is written to a hash-chained audit log. A FastAPI review UI and an MCP adapter share the same service.
• On 60 held-out fictional tickets the rules baseline produced 37/60 fully correct proposals vs 25/60 for the local model, so I kept rules as the default.
Reachboard — Django workflow showcase · *Fictional data · browser demo is a simulation* | github.com/erfanpj/reachboard-showcase
• Django campaign workflow with server-authoritative pricing, ownership checks, CSRF-protected checkout, explicit state transitions, audit history and idempotent submission (a repeated submit adds no duplicate history).
Breast cancer classifier comparison · *Completed evaluation · public dataset* | github.com/erfanpj/Breast_Cancer_Project
• Rebuilt an earlier analysis with leakage-safe pipelines, nested cross-validation and a held-out test set scored once; automated tests check that no fit sees a test row.
• Tuned MLP F1 0.950 vs 0.951 for plain logistic regression on 143 held-out samples, so the simpler model is just as good. Not a clinical tool.
Exploratory Alzheimer’s data analysis in Julia · *Descriptive analysis · synthetic data* | github.com/erfanpj/exploratory_alzheimers
• Descriptive analysis of a synthetic dataset (2,149 records) with validation against the data card, recorded cleaning counts, provenance notes, 95% intervals and 49 tests. Results describe the data generator; no clinical claims.
